# Movie Ticket Booking Calculator

A simple Python project that calculates a movie ticket price based on the user's age, membership status, seat type, show time, and weekend status.

## Features

- Checks ticket booking eligibility based on age
- Checks eligibility for evening shows
- Applies membership discounts
- Calculates weekend and evening extra charges
- Calculates service charges based on seat type
- Calculates the final ticket price
- Demonstrates `if`, `elif`, and `else` statements
- Demonstrates `and` and `or` logical operators
- Demonstrates nested `if` statements
- Uses Boolean values and conditional logic

## Technologies Used

- Python 3

## Example

The calculator uses a base ticket price of `15` and calculates additional charges and discounts based on the user's selections.

## Purpose

This project was created as a Python programming practice exercise to understand Boolean values, conditional statements, logical operators, and basic calculations.
